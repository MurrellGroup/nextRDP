# Session 18 handoff

## Checkpoint boundary

Session 18 advances the engine to `0.18.0-session-18` while retaining project schema
`org.rdp-web.project/v1alpha16`; no durable analysis field changed. It adds a cosmetic Windows 95
skin and repairs the stop boundary during cyclic discovery. The numerical discovery, reconciliation,
review, and export algorithms are otherwise unchanged from Session 17.

## Windows 95 skin

- The browser remains a responsive single-page application, but its visible shell now uses the
  Windows 95 system palette: teal desktop, navy active title bar, gray application face, and square
  white/gray/black bevels.
- A classic title bar, decorative window controls, menu strip, workflow panel, and three-field
  status bar replace the modern translucent dashboard chrome.
- Buttons, inputs, selects, list views, tables, tabs, notices, evidence cards, plots, tree and
  alignment panes, metrics, and export panels share raised or recessed Win95 geometry.
- Scan progress uses a recessed white trough and segmented navy blocks instead of the earlier
  rounded gradient bar.
- Typography uses local `Tahoma` / `MS Sans Serif`-style system fallbacks, with `Courier New` for
  tabular scan and metric values. No font, image, or network dependency was added.
- Narrow layouts retain the same functionality through a raised workflow drawer and condensed
  menu/status regions. The skin is CSS/markup only and does not alter analytical inputs or results.

## Graceful cyclic stop

The previous cancellation path returned worker status 2, threw away the scan promise in the UI,
and left already completed cyclic events inaccessible. The engine now treats a user stop at a batch
boundary as a successful early terminal condition:

1. Signals generated by the unfinished discovery round are discarded from `round_signal_begin_`.
2. Every event and supporting signal committed by earlier complete rounds is retained.
3. Transient cyclic shortlist state is cleared so incomplete summaries cannot enter the result.
4. The engine records `cycleTermination = "user-stopped"`, enters ordinary reconciliation, and
   returns a normal result object to Review.

Stopping in the opening round is also safe: it can yield a valid zero-event result because no
event is committed until a round completes. Cancellation during the reconciliation phase remains
disabled because that bounded stage is already finalizing the retained evidence set.
